# 🚀 MacBook Pro M2 Pro - Yazılımcı İçin Hız & Estetik Odaklı Uygulama Listesi

GitHub `README.md` dosyanıza doğrudan ekleyebileceğiniz, şu ana kadar konuştuğumuz ve kurulumunu yaptığınız tüm uygulamaların (ve üzerine eklediğim birkaç ekstra geliştirici aracının) derlenmiş tablosu:

| Uygulama | Açıklama | Bağlantı |
| :--- | :--- | :--- |
| **Ghostty** | Zig diliyle yazılmış, GPU hızlandırmalı, ultra hızlı ve minimalist yeni nesil terminal. | [Resmî Site](https://ghostty.org/) |
| **Ice** | macOS menü çubuğundaki (Menu Bar) simgeleri gizleyen ve düzenleyen güçlü, native araç. | [GitHub](https://github.com/jordanbaird/Ice) |
| **boringNotch** | MacBook çentiğini (notch) estetik bir işlevsel panele dönüştüren modern özelleştirme aracı. | [GitHub](https://github.com/marisand/boringNotch) |
| **AeroSpace** | macOS için SIP kapatmayı gerektirmeyen, klavye odaklı i3/Hyprland benzeri tiling window manager. | [GitHub](https://github.com/nikitabobko/AeroSpace) |
| **Zed** | Atom ve VS Code yaratıcıları tarafından Rust ile yazılmış, GPU mimarili ışık hızında kod editörü. | [Resmî Site](https://zed.dev/) |
| **Cursor** | VS Code ekosistemini tamamen yapay zeka (AI-first) ile entegre eden modern kod editörü. | [Resmî Site](https://www.cursor.com/) |
| **Raycast** | Spotlight alternatiflerinin zirvesi; eklenti desteği, clipboard yönetimi ve hız canavarı arayüzü. | [Resmî Site](https://www.raycast.com/) |
| **Yaak** | Postman yerine Tauri ve Rust ile yazılmış, aşırı hızlı ve şık API (gRPC, HTTP, GraphQL) istemcisi. | [Resmî Site](https://yaak.app/) |
| **GitButler** | GitHub kurucusu tarafından geliştirilen, sanal dallanma (virtual branches) destekli sıra dışı Git GUI. | [Resmî Site](https://gitbutler.com/) |
| **Fork** | macOS için Swift ile yazılmış, karmaşık branch ağaçlarını yağ gibi akan bir performansla sunan Git istemcisi. | [Resmî Site](https://git-fork.com/) |
| **Stats** | Menü çubuğundan M2 Pro işlemci çekirdeklerini, RAM ve disk durumunu izleyen native sistem monitörü. | [GitHub](https://github.com/exelban/stats) |
| **Arc Browser** | Sekme yönetimini dikey barda çözen, Spaces özelliğiyle iş/kişisel ayrımı sunan şık tarayıcı. | [Resmî Site](https://arc.net/) |
| **TablePlus** | Veritabanı yönetimi için ağır Java araçları yerine tamamen Swift ile yazılmış native ve hızlı SQL istemcisi. | [Resmî Site](https://tableplus.com/) |
| **CleanShot X** | Ekran görüntüsü alma, video/GIF kaydetme ve üzerine estetik açıklamalar ekleme konusunda Mac'teki en iyi araç. | [Resmî Site](https://cleanshot.com/) |
| **Shottr** | CleanShot X'e ücretsiz ve piksel hassasiyetinde çalışan hafif (lightweight) bir ekran görüntüsü alternatifi. | [Resmî Site](https://shottr.cc/) |
| **DevToys** | Yazılımcılar için JWT decode, JSON formatlama, Regex test gibi araçları içeren çevrimdışı İsviçre çakısı. | [Resmî Site](https://devtoys.app/) |
| **LocalSend** | Wi-Fi üzerinden tüm cihazlar (Mac, Linux, Windows, Android) arasında AirDrop hızında dosya paylaşım aracı. | [Resmî Site](https://localsend.org/) |
| **Warp** | Rust tabanlı, yapay zeka destekli ve modern bir text editörü gibi çalışan alternatif terminal. | [Resmî Site](https://www.warp.dev/) |
